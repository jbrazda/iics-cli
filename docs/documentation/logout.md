# logout

Invalidate the current session and remove the cached token.

## Synopsis

```bash
iics logout [flags]
```

## Flags

This command has no command-specific flags. All [global flags](../../README.md#global-flags) apply.

## Examples

```bash
# Logout from the default profile
iics logout

# Logout from a named profile
iics logout --profile prod
```
